# OmanPay

Prototipo web que simula una app móvil de billetera digital para Omán.

## Funciones

- Transferencias por teléfono, recargas Omantel y pago de servicios simulados.
- Pago QR de demostración, comprobantes e historial.
- Saldo y estadísticas actualizados con persistencia local en el navegador.
- Diseño móvil con marco de teléfono en escritorio.

## Ejecutar

Abre `index.html` en un navegador o sirve esta carpeta con cualquier servidor estático. No requiere instalación ni compilación.

## GitHub Pages

Configuración: **Settings → Pages → Deploy from a branch → main → / (root)**. Cada actualización de la rama se publica automáticamente.

## Alcance

Prototipo académico. No procesa dinero real, no usa la cámara y no se conecta con bancos ni proveedores de servicios. Los datos de prueba se guardan en localStorage. Las tipografías se cargan desde Google Fonts cuando hay conexión.
